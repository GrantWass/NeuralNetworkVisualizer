# Google Search Console setup

Status: the domain property **already exists and is verified** in Google Search
Console as a domain property (`sc-domain:nn-visual.com`). No verification work
is needed.

## Remaining step: grant the Agent City service account read access

Under **Settings > Users and permissions** in
[Search Console](https://search.google.com/search-console), add:

```
agentcity@mercurial-craft-505718-f8.iam.gserviceaccount.com
```

with the **Delegated owner** permission. This lets the Agent City analytics
service account read Search Console data for nn-visual.com.

## Sitemap

The site serves a sitemap at `https://www.nn-visual.com/sitemap.xml`
(generated by `neural-network-visual/app/sitemap.ts`) and it is referenced from
`/robots.txt`, so Google can discover it automatically.

Whether it has been explicitly submitted in Search Console is unconfirmed from
the repo — check under **Sitemaps** in Search Console for
`https://www.nn-visual.com/sitemap.xml`. If it is not listed, submit it there.
(Indexing already works: pages are receiving impressions and clicks, so this is
a hygiene step rather than a blocker.)
